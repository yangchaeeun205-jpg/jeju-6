01 · Problem

왜 이 서비스가 필요한가

파는 쪽과 사는 쪽의 '수량'이 서로 맞지 않아, 멀쩡한 농산물이 그대로 버려집니다.

🚜

농가 · 판매자

  • · 모양·크기가 고르지 않은 못난이 농산물은 정규 유통망에 넣기 어렵다
  • · 판매 후 조금씩 남는 잉여 농산물은 수량이 적어 별도 판매처를 찾기 힘들다
  • · 결국 버리거나 헐값에 넘기게 되어 수익과 자원이 함께 손실된다
🧺

청년 · 1인 가구

  • · 시중 농산물은 10kg 단위 대용량 중심이라 부담이 크다
  • · 혼자 다 먹지 못해 남기고 버리는 경험이 반복된다
  • · 소량으로 파는 곳이 어디 있는지 정보가 흩어져 있다
💡

"적은 수량이라 못 파는 사람"과 "적은 수량만 필요한 사람"을 한 화면에서 연결하면 두 문제가 동시에 풀린다.

06 · Consumer

소비자 페이지 — 찾고, 보고, 고른다

필터로 범위를 좁히고, 지도로 위치를 확인하고, 카드로 조건을 비교합니다.

🎛️

지역 · 품목 필터

  • · 기본값은 모두 전체
  • · 두 필터를 동시 적용 가능
    (예: 애월읍 + 채소)
  • · 판매자 등록 화면과 같은 고정 목록을 공유해 표기 차이로 누락되지 않도록 함
🗺️

제주 픽업 지도 (Leaflet)

  • · 제주도 전체가 보이는 화면으로 시작
  • · 픽업 장소를 마커로 표시
  • · 같은 장소는 하나의 마커로 묶음
  • · 마커 클릭 → 장소명 + 상품명 팝업
🃏

상품 카드

  • · 상품명 · 판매자 · 품목 · 단위
  • · 가격 (예: 1kg / 3,000원)
  • · 지역 · 남은 수량 · 마감시간
  • · 예약 상태 + 예약하기 버튼
상태 표시 규칙
예약 가능 남은 수량 ≥ 1 & 마감 전
품절 남은 수량 = 0
예약 마감 마감시간 경과
둘 다 해당하면 '품절' 우선
07 · Core Logic

핵심 로직 — 잔여 수량 계산

이 플랫폼의 심장. 예약이 쌓일 때마다 모든 화면의 숫자가 같은 식으로 다시 계산됩니다.

준비 수량 − 누적 예약 수량 = 남은 수량

누적 예약 수량 = 해당 상품 id로 저장된 모든 예약 행의 수량 합계

📌 예시

모양이 고르지 않은 감귤 (1kg)

준비 수량 20

예약 A 2 + 예약 B 3 = 누적 5

→ 남은 수량 15 · 예약 가능

🔒 품절 자동 처리

예약 저장 후 남은 수량이 0이 되면 즉시 품절로 바뀌고, 상품 카드는 목록에서 지우지 않되 예약하기 버튼을 비활성화해 추가 예약을 막습니다.

⏱️ 예약 직전 재확인

'예약 확정' 순간에 최신 예약 데이터를 다시 읽어 수량과 마감시간을 재검사합니다. 그 사이 다른 사람이 먼저 예약했다면 저장하지 않고 현재 가능한 수량을 안내합니다.

예약은 행을 추가만 합니다. 수량을 덮어쓰지 않으므로 누가 얼마나 예약했는지 이력이 그대로 남고, 남은 수량은 언제든 합계로 다시 구할 수 있습니다.

🔌 저장소는 교체 가능한 구조

데이터 입출력을 Store 한 곳에 모아 두고, 화면 코드는 Store만 호출합니다. 현재 시연 버전은 브라우저 저장소(localStorage)를 쓰지만, fetchProducts / fetchReservations / addProduct / addReservation 네 함수만 바꾸면 Google Sheets(Apps Script 웹앱) 연동으로 그대로 교체됩니다.

🔄 데이터를 다시 읽는 4가지 순간

① 페이지 최초 접속
② 상품 등록 완료
③ 예약 완료
④ 최신 정보 불러오기

일정 시간마다 반복 조회하지 않습니다 — 불필요한 요청을 줄이고, 갱신 시점을 사용자가 통제하도록 했습니다.

10 · Edge Cases

예외 상황 처리

"잘 되는 경우"보다 "안 되는 경우"를 먼저 정의했습니다. 잘못된 데이터는 저장하지 않습니다.

수량 초과

남은 수량보다 많이 예약 → 저장하지 않고 현재 가능한 수량 안내

예약 중 품절

확인 후 확정 전에 품절 → 저장 중단, 품절 안내 후 화면 갱신

예약 중 마감

확정 직전 마감시간 경과 → 예약 마감 안내 후 진행 중단

잘못된 수량

0 · 음수 · 문자 입력 → 1 이상의 정수를 다시 입력하도록 안내

필수 항목 누락

닉네임·수량 등 미입력 → 저장하지 않고 누락 항목을 안내

지난 마감시간

이미 지난 시간으로 등록 시도 → 현재 시간 이후로 입력하도록 안내

상품이 없음

빈 화면 대신 "현재 등록된 농산물이 없습니다."

필터 결과 없음

"선택한 조건에 맞는 상품이 없습니다." 안내

불러오기 실패

임의의 값을 보여주지 않고 "불러오지 못했습니다." + 다시 불러오기 버튼
